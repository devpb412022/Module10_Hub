# EASA Part-66 Module 10 — Aviation Legislation (Study Site)

เว็บสรุปเนื้อหา Module 10 (CAT A / B1 / B2) สองภาษา EN | TH พร้อมแผนอ่าน 21 วัน แบบทดสอบท้ายบท
และข้อสอบจริง 63 ข้อ (3 ตัวเลือก) ที่มี Key เฉลย และเลขหน้าอ้างอิง

- ไฟล์เดียวจบ: `index.html` (ไม่มี build step, ไม่มี dependency นอกจาก Google Fonts)
- ความคืบหน้าเก็บใน localStorage ของเบราว์เซอร์ ไม่มีการส่งข้อมูลไปที่ใด
- เนื้อหาเป็นสรุปเพื่อการศึกษา อ้างอิงหนังสือ Aero-Bildungs (12/2024) ควรตรวจสอบกับ EASA Implementing Regulations ฉบับปัจจุบันเสมอ

## Deploy (GitHub Pages)

```bash
git init
git add .
git commit -m "Add M10 Aviation Legislation study site"
git branch -M main
git remote add origin https://github.com/devpb412022/m10-legislation.git
git push -u origin main
```

แล้วไปที่ Settings → Pages → Source: `main` / `(root)` เว็บจะอยู่ที่
`https://devpb412022.github.io/m10-legislation/`
